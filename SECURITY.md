# Security reporting

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/ddocde/Ai-Clash_Cli/security/advisories/new). Do not publish credentials, working exploit details or private configurations in public issues. If private reporting is unavailable, open a minimal issue requesting a private reporting channel without sensitive details.

Version 0.1.x is a preview. Security fixes are applied to the latest preview; older previews are not maintained independently. TUN and privileged service behavior passed isolated Docker acceptance; native-host SSH/IPv6 acceptance remains pending, so these features remain preview functionality.

请通过 GitHub 私密漏洞报告反馈安全问题，请勿在公开 Issue 中发布凭据、私有配置或可直接利用的细节。当前 0.1.x 为预览版本，安全修复仅面向最新预览版。
